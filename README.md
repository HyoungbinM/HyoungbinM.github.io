# hyoungbinm.github.io

Personal academic homepage of Hyoungbin Moon, served with GitHub Pages.

- `index.html` — page content (edit this to update the CV sections)
- `style.css` — styling, light/dark theme, print layout
- `Moon_HB_CV.pdf` — downloadable CV (replace this file to update the PDF)
- `.nojekyll` — tells GitHub Pages to serve the files as-is, without Jekyll

No build step. Push to `main` and GitHub Pages redeploys within about a minute.
